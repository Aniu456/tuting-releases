# 汽酷音乐 (tuting)

兔听，桌面端的酷狗音乐播放器（macOS）。本仓库只用于发布安装包和展示运行截图，源码暂不开源。

## 下载

前往 [Releases](https://github.com/Aniu456/tuting-releases/releases/latest) 下载最新版本的 zip，解压后拖入「应用程序」即可。
